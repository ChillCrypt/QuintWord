# 🔧 Решение проблемы: ERR_CONNECTION_REFUSED

## Проблема
Вы видите ошибку: `ERR_CONNECTION_REFUSED` при попытке открыть localhost:3000

**Причина:** Сервер разработки не запущен, потому что Node.js не установлен или не найден системой.

## ✅ Решение

### Шаг 1: Установите Node.js (если еще не установлен)

1. **Откройте браузер** и перейдите на: **https://nodejs.org/**
2. **Нажмите на зеленую кнопку LTS** (рекомендуемая версия)
3. **Скачайте** файл установки (например, `node-v20.11.0-x64.msi`)
4. **Запустите** скачанный файл
5. **Установите** Node.js (нажимайте "Next" на каждом шаге)
6. **Важно:** Оставьте все галочки по умолчанию (особенно "Add to PATH")

### Шаг 2: Перезапустите компьютер (или хотя бы Cursor)

После установки Node.js **обязательно**:
- **Закройте Cursor полностью**
- **Перезагрузите компьютер** (или хотя бы перезапустите Cursor)
- Это нужно, чтобы система "увидела" новую установку

### Шаг 3: Проверьте установку

Откройте **НОВЫЙ** терминал в Cursor (`` Ctrl + ` ``) и выполните:

```bash
node --version
```

Должна показаться версия, например: `v20.11.0`

Затем:

```bash
npm --version
```

Должна показаться версия, например: `10.2.4`

**Если версии показываются** - отлично! ✅ Переходите к шагу 4.

**Если ошибка "не является командой"** - значит:
- Node.js не установлен, или
- Терминал не перезапущен, или
- Node.js не добавлен в PATH

**Решение:** Перезагрузите компьютер и попробуйте снова.

### Шаг 4: Установите зависимости проекта

В терминале выполните:

```bash
cd C:\Users\Kirill\base-wordle
```

Затем:

```bash
npm install
```

**Важно:** Дождитесь завершения установки (1-3 минуты). Вы увидите много текста - это нормально!

В конце должно быть написано что-то вроде:
```
added 500 packages in 2m
```

### Шаг 5: Запустите сервер разработки

Выполните:

```bash
npm run dev
```

**Вы должны увидеть:**
```
  ▲ Next.js 14.2.0
  - Local:        http://localhost:3000
  - Ready in 2.5s
```

**Важно:** 
- **НЕ закрывайте терминал!** Сервер должен работать постоянно
- Если вы закроете терминал, сервер остановится

### Шаг 6: Откройте браузер

После того как увидите "Ready", откройте браузер и перейдите на:

**http://localhost:3000**

Теперь должно работать! 🎉

## Частые проблемы

### Проблема: После установки Node.js команды все равно не работают

**Решение:**
1. **Полностью перезагрузите компьютер** (не просто перезапустите Cursor)
2. Откройте терминал заново
3. Попробуйте: `node --version`

### Проблема: npm install выдает ошибки

**Решение:**
- Убедитесь, что вы в правильной папке: `cd C:\Users\Kirill\base-wordle`
- Проверьте интернет-соединение
- Попробуйте удалить папку `node_modules` (если есть) и запустить `npm install` снова

### Проблема: Сервер запускается, но сайт не открывается

**Решение:**
- Убедитесь, что сервер действительно запущен (видите "Ready" в терминале)
- Проверьте, что используете правильный адрес: **http://localhost:3000** (не https!)
- Попробуйте другой браузер
- Проверьте, не блокирует ли антивирус или брандмауэр соединение

### Проблема: Порт 3000 уже занят

Если видите ошибку "Port 3000 is already in use":

**Решение:**
1. Найдите процесс, использующий порт 3000:
   ```bash
   netstat -ano | findstr :3000
   ```
2. Или просто используйте другой порт:
   ```bash
   npm run dev -- -p 3001
   ```
3. Тогда откройте: http://localhost:3001
