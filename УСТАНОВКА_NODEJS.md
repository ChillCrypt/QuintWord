# 📥 Как установить Node.js (пошаговая инструкция)

## Проблема
Вы видите ошибку: `"next" не является внутренней или внешней командой`

Это означает, что на вашем компьютере не установлен **Node.js**.

## Решение: Установите Node.js

### Шаг 1: Скачайте Node.js

1. Откройте браузер
2. Перейдите на сайт: **https://nodejs.org/**
3. Вы увидите две кнопки:
   - **LTS** (рекомендуется) - стабильная версия
   - **Current** - последняя версия
4. Нажмите на кнопку **LTS** (зеленая кнопка)
5. Начнется скачивание файла `node-vXX.X.X-x64.msi`

### Шаг 2: Установите Node.js

1. Найдите скачанный файл (обычно в папке **Загрузки**)
2. Дважды кликните на файл `node-vXX.X.X-x64.msi`
3. Откроется мастер установки
4. Нажимайте **Next** (Далее) на каждом шаге
5. **Важно:** Оставьте галочку "Automatically install the necessary tools" (если есть)
6. Нажмите **Install** (Установить)
7. Дождитесь завершения установки (1-2 минуты)
8. Нажмите **Finish** (Готово)

### Шаг 3: Перезапустите терминал

**Очень важно!** После установки Node.js нужно:

1. **Закройте все открытые терминалы** (включая Cursor, если он открыт)
2. **Перезапустите Cursor** (или откройте новый терминал)
3. Это нужно, чтобы система "увидела" новую установку Node.js

### Шаг 4: Проверьте установку

Откройте новый терминал и выполните:

```bash
node --version
```

Должна показаться версия, например: `v20.11.0`

Затем:

```bash
npm --version
```

Должна показаться версия, например: `10.2.4`

Если версии показываются - отлично! ✅

### Шаг 5: Установите зависимости проекта

Теперь перейдите в папку проекта:

```bash
cd C:\Users\Kirill\base-wordle
```

И выполните:

```bash
npm install
```

Это установит все необходимые библиотеки (Next.js, React и т.д.)

Процесс займет 1-3 минуты. Вы увидите много текста - это нормально!

### Шаг 6: Запустите проект

После установки выполните:

```bash
npm run dev
```

Приложение запустится на http://localhost:3000

## Если что-то пошло не так

### Проблема: После установки команды все равно не работают

**Решение:**
1. Полностью закройте Cursor/терминал
2. Перезагрузите компьютер (на всякий случай)
3. Откройте терминал заново
4. Попробуйте снова: `node --version`

### Проблема: Не могу найти скачанный файл

**Решение:**
- Проверьте папку **Загрузки** (Downloads)
- Или в браузере нажмите `Ctrl + J` чтобы открыть список загрузок

### Проблема: Ошибка при установке

**Решение:**
- Убедитесь, что у вас есть права администратора
- Попробуйте запустить установщик от имени администратора (правой кнопкой → "Запуск от имени администратора")

## Альтернативный способ: Через Chocolatey (для продвинутых)

Если у вас установлен Chocolatey, можно установить через команду:

```bash
choco install nodejs
```

Но для новичков лучше использовать способ выше (через официальный сайт).
